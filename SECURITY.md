# Reporting security issues

Do not post API keys, raw device dumps or personal recordings in public issues. Report a minimal reproduction with synthetic data and the affected version. Use GitHub private vulnerability reporting if the repository owner enables it; otherwise contact the maintainer privately before publishing sensitive details.

The model is not a trusted hardware controller. All returned identifiers and fields are validated. The privileged uploader is narrowly scoped to the identity-checked robot card; review filesystem and privilege boundaries carefully when modifying it.
