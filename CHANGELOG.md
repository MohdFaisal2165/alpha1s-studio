# Changelog

## 0.3.0 — Embodied AI Studio preview

- Integrated simultaneous robot speech and approved native gesture playback.
- Added exact verified pair replay and retained no-retry handling for uncertain delivery.
- Organized Pose Studio, Voice, Greetings, Conversation and Storage workflows.
- Included preset expressive voices, microphone questions and optional secure key storage.
- Added first-run read-only card backup/import and an environment checker.
- Prepared a clean source distribution, pre-created runtime folders, user guides and offline CI.

Compatibility is limited to the documented Linux/hardware/firmware/card configuration. Fresh speech still requires a USB upload and physical unplug before Bluetooth playback.
